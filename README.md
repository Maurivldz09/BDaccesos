# 🛡️ Control de Acceso Residencial

Sistema de gestión y monitoreo en tiempo real de entradas y salidas para fraccionamientos residenciales.

## 🛠️ Tecnologías
- **Frontend:** HTML5, CSS3 (Corporate Slate), JavaScript (ES6+)
- **Base de Datos & Backend:** Supabase (PostgreSQL Cloud), PHP (PDO), MySQL
